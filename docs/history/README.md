# Historical reports (≤ 1.7.3)

These are earlier test and deployment reports, kept for traceability only. They are **not** reruns of 1.7.4; current results are in [../VALIDATION.md](../VALIDATION.md) and [../e2e-results.json](../e2e-results.json).

- `live-*`, `review-*`, `revision-*`, `representative-*`: real-model and browser runs from earlier revisions, including the failing first attempts that led to fixes.
- `deployment-*`, `*-spend-snapshot.json`, `live-test-spend.json`: earlier deployment checks and spend ledgers.
- `TECHNICAL_GUIDE-1.7.3.pdf`: the 1.7.3 five-page export of the technical guide (Chinese). The current guide is [../TECHNICAL_GUIDE.md](../TECHNICAL_GUIDE.md).

Host addresses and local ledger paths in these files were replaced with placeholders (`demo-host`, `<local-ledger-dir>`). The `evals/` scripts still write new runs to `docs/` by default.
